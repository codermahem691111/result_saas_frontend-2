# School Admin Frontend (Next.js + Tailwind)

1. `yarn install`
2. `yarn dev`  -> http://localhost:3000

The API defaults to `https://result-saas-backend.onrender.com/` for both the main and result services. Override `NEXT_PUBLIC_API_URL` or `NEXT_PUBLIC_RESULT_API_URL` in `.env.local` if needed.
Admin login uses the email/password set in the backend `.env`.
